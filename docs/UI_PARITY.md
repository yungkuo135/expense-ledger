# 交易清單改版功能對照

2026-09-23：對照 `renderClassicLedger`、`renderItemRow`、 `attachLedgerHandlers`
與新版 `transaction-workspace.js`。

| 舊版功能                               | 新版位置／處理                                  |
| -------------------------------------- | ----------------------------------------------- |
| 月份總額、收合，預設最新月份           | 補回月份標題與原生 details；篩選時展開結果      |
| 日期與當日小計                         | 補回日期列右側；與月份總額均使用 isCounted      |
| 現金／信用卡／發票圖示                 | 清單種類欄保留                                  |
| 店家、備註、分類、銀行                 | 清單摘要與詳情；手機分類在詳情內                |
| 發票號碼、品項數                       | 補回清單 metadata 與詳情標題                    |
| 個人金額、原始金額、已修改提示         | 補回清單原始合計與修改標記；詳情沿用原 renderer |
| 平台費排除說明                         | 清單標記與詳情說明；不變更排除規則              |
| 已配對信用卡與銀行、不重複計入提示     | 清單補回銀行及提示；詳情保留卡片資訊與解除配對  |
| 信用卡待確認、建議配對                 | 清單補回提示；詳情保留確認／合併／非此筆        |
| 金額、分類、備註、銀行編輯、刪除與復原 | 詳情沿用 renderItemRow / attachLedgerHandlers   |
| 批次確認                               | 待處理頁保留                                    |
| 搜尋／來源／分類／月份／處理狀態篩選   | 頁首搜尋展開，收合後仍顯示條件                  |
| 空結果提示                             | 清單內保留                                      |
| 發票細項展開                           | 改為詳情側欄／手機底部面板，純查看不重建清單    |
| 匯入、備份、批次紀錄、統計、品質工作箱 | 分別在匯入／分析／待處理頁，不在此次改動中移除  |

驗證：`deno task test` 與 `deno run -A scripts/verify-workspace.js`。
瀏覽器使用隔離的記憶體合成資料，桌機與手機尺寸；不登入正式帳本。
瀏覽器涵蓋小計、原始金額、零元分帳、月份收合、平台費、搜尋、
金額／備註／銀行／分類編輯、確認、合併與解除配對、詳情捲動及焦點保留。
未將此驗證視為正式 Supabase 或所有實體裝置的端到端驗收。
