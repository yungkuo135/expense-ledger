# 後續待辦

本文件只記錄尚未承諾時程的工作。開始實作前，應重新確認需求、風險與優先順序。

## 近期維護

- 完成正式裝置的 smoke test：登入、記帳、編輯、匯入預覽、對帳、JSON 匯出與登出。
- 定期匯出完整 JSON 備份，保存在 repository 之外，並偶爾用測試環境驗證可還原。
- Supabase Auth 維持關閉公開註冊，部署網址變更時同步更新 Redirect URLs。
- 更新 Supabase JS 固定版本時先閱讀 release notes，再跑完整回歸測試。

## 資料累積後評估

- 約累積 6～12 個月後量測初始載入時間及 Supabase request 數量。
- 若需要按月延遲載入，必須一起設計：
  - 月份索引與按需抓取。
  - 已載入月份的記憶體 cache。
  - 跨月搜尋與分析的完整資料載入提示。
  - JSON 完整備份時載入全部月份。
  - 匯入去重與信用卡／發票跨月對帳。
  - 批次回滾及刪除空月份的行為。
- 不可只讓首頁少顯示資料，就誤認為資料庫已按月查詢。

## 未來功能

- PWA 安裝體驗與靜態資源快取。
- 經過衝突策略設計後，再評估離線寫入與重新同步；不可直接以 localStorage fallback
  代替同步機制。
- 視實際使用需求評估更完整的多裝置同步狀態、錯誤重試與資料版本控制。

## 暫不進行

- 不為了技術偏好改寫成 React／Next.js。
- 不把 service-role key、secret 或資料庫密碼放進瀏覽器。
- 不在沒有 migration 與備份相容計畫時改變 storage key 或 entry schema。
- 不自動合併瀏覽器舊資料與雲端資料。
